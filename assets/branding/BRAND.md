# Cunning — brand assets

Quick reference for the game's visual identity and where each asset lives.
Everything here is generated by script (see **Regenerating** below), so any
tweak should go into the script, not the output files.

## Colors

| Use                  | Hex       |
|----------------------|-----------|
| Background, dark     | `#0a0505` |
| Background, maroon   | `#4a0e16` |
| Gold accent (rings, rules) | `#c9a227` |
| Bright gold (text, highlights) | `#f0c93d` |

The numbered card faces (1-9) use a rainbow sweep of hues instead — see
`build_palette()` in `scripts/gen_cards.py`. Card 10 uses this same
maroon/gold/black scheme, tying the rarest card to the brand and back design.

## Font

Poppins ExtraBold (SIL Open Font License 1.1), subset to only the glyphs
actually used — `C G I N U` and `0-9` — and embedded directly in every SVG
as base64 woff2, so nothing depends on the font being installed. See
`fonts/NOTICE.md` for attribution. If new text is ever added to a design
(a tagline, extra wordmark, etc.), the subset in
`fonts/Cunning-Poppins-subset.woff2` needs regenerating first with the
additional characters, or the new glyphs will silently fall back to a
generic system font.

## Mascot art

`assets/nexxus.png` is the source character art. Two crops of it are reused
throughout:
- **Head crop** — square, face/torso/wings, used for the circular medallion
  (card back, square logo, icon/favicon).
- **Panel crop** — tall, full body, used for the side panel in the
  widescreen logo formats, faded into the background on its left edge.

## Asset map

| File | Size | Use |
|---|---|---|
| `game-logo-square.png` | 1200x1200 | Profile pictures, app/store square listings |
| `game-logo-4x3.png` | 1600x1200 | General marketing, print |
| `game-logo-16x9.png` | 1920x1080 | Video thumbnails, wide marketing |
| `game-logo-banner.png` | 1920x480 | Website header |
| `social-preview.png` | 1200x630 | Open Graph / Twitter card link preview |
| `icon/icon-512.png` … `icon-16.png` | 512/192/48/32/16 | App icons, chat avatars |
| `icon/favicon.ico` | 16/32/48 multi-res | Browser favicon |

The icon/favicon set deliberately drops the "CUNNING" wordmark — at those
sizes text is illegible, so it's the medallion mark alone.

Publisher branding (`assets/logo-gold.png` / `assets/logo-red.png`, the
NXD Multimedia logo) is separate from the game's own branding above; the
scripts pick whichever text color contrasts best against a given
background.

## Regenerating

```
python3 scripts/gen_cards.py   # playing cards: faces, back, print-ready set
python3 scripts/gen_logo.py    # game logos, social preview, icon/favicon set
```

Both scripts are idempotent — safe to re-run after editing colors, crops,
or layout constants at the top of each file.
